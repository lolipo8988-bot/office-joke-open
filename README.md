# office-joke-open

Entry for the make.fun competition **Make the AI Judge Laugh: the Office Joke Open**
([competition page](https://make.fun/competitions/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232)).

`main.py` writes one line — a single original joke about office life — to
`/output/entry.txt` as UTF-8. The text is 143 characters, inside the gate's
1-to-200 character limit, and the program is deterministic: every run writes
exactly the same bytes.

The joke: the boss says "take this offline," the narrator takes him
literally and unplugs the router — and IT delivers the verdict that makes
it land.

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (override the directory with
`MAKEFUN_OUTPUT_DIR` for local testing).
